# Changelog

## 1.0.21.3

- Break/Miss 判定特效改为按音符当前屏幕像素尺寸缩放
- 判定图形、文字和文字区域会随摄像机缩放同步变化
- 所有 DX 音符恢复每帧浮动状态更新
- 修复重启游戏后必须重新调整设置才恢复浮动的问题
- 保留 1.0.21.2 的全量特效和共享渲染优化

## 1.0.21.2

- 撤回可见性裁剪，所有 DX 音符仍创建并保留完整特效
- 相同原始网格共享一份表面网格和一份发光网格
- 表面和六层发光共享材质，通过 MaterialPropertyBlock 独立改色
- 复用发光缩放、透明度和材质属性块，减少逐帧分配
- 镜头外对象保持存在，仅跳过不可见的材质和发光计算
- 保留 1.0.21 原有的可见特效外观与判定逻辑

## 1.0.21.1

- 严格基于 1.0.21 优化游戏内 DX 渲染性能
- 只有实际可见音符执行表面改色、浮动和六层发光更新
- 为当前进度后的 10 个音符提前创建并隐藏资源
- 隐藏资源提前完成几何初始化，进入画面后立即显示
- 几何轮廓刷新限制为每 0.1 秒一次
- 复用集合和清理列表，移除逐帧 HashSet 与 ToList 分配
- 保留 1.0.21 原有的可见特效外观和判定行为

## 1.0.21

- DX 判定扩展至中旋、HOLD、HOLD 释放、多押、自动音符和多星球音符
- HOLD 链与自动衔接按自动判定记录，避免沿用旧角度导致误判
- 多押只在最终离开 DX 音符时计一次
- 同一拍可同时记录多个不同 DX 音符
- 日志新增 DX 音符类型、判定结果和命中序号，便于实机核对

## 1.0.20

- 结算 X 准度恢复原版标签和两位小数格式
- 本模组额外准度紧跟百分号显示为 `(+x.xx%)`
- 移除结算四位小数和下一行居中方案
- 保留结算追踪器修复，确保额外奖励稳定显示

## 1.0.19

- 修复结算额外 X 准度不显示
- 结算处理使用游戏传入的实际判定追踪器
- 结算 X 准度支持数字与百分号之间存在颜色标签
- 实时 DX-Accuracy 颜色小标跟随当前轨道主色
- 排列为“准度 | DX-Accuracy”时颜色小标移至右侧

## 1.0.18

- 实时 DX-Accuracy 改为 0% 至 1% 线性显示
- 实时 DX-Accuracy 保留四位小数
- 结算 X 准度改为四位小数

- 补齐 Audio presets 和 Add preset 的 8 种非中英翻译
- 校验全部语言表，核心 40 项无缺失

## 1.0.17
